# ADR-069 — Локализация пресетов (`GET /v1/presets`)

- **Статус:** Accepted
- **Дата:** 2026-09-18
- **Связано:** [ADR-035](ADR-035-prompt-presets-endpoint.md), запрос iOS («в пресеты локаль нужно добавить»), порт claude-ios ADR-049

## Контекст

Каталог `GET /v1/presets` был только на английском. iOS-клиент должен показывать чипы на языке пользователя (для `avorelio.shop` — русский).

## Решение

Локализуются только `title` и `prompt`. `id` и `icon` стабильны и не переводятся. Поддерживаемые локали: `en` (канон/fallback), `ru`. Резолв в роутере, first match:

1. `?locale=` — явное значение; неподдерживаемое → `422`
2. `Accept-Language` — первый поддерживаемый primary-subtag (`ru-RU` → `ru`); иначе тихий fallback
3. `PRESETS_DEFAULT_LOCALE` (per-instance, дефолт `en`)
4. `en`

Ответ аддитивно получает поле `locale` (фактически применённый язык). Форма элемента `{id, title, icon, prompt}` не меняется. Без миграции БД.
